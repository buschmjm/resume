Infrastructure Engineer

Design and build internal AI systems while running the platform and release infrastructure behind more than 300 white-label iOS and Android apps in production. On-call owner and final escalation point for production incidents.

  • Designed and launched a general-purpose AI agent platform, now rolling out to internal teams. Anyone can submit work from a CLI, an Airflow DAG or the API. A FastAPI dispatcher queues it in PostgreSQL and runs each attempt as a short-lived Kubernetes Job. Ordinary code, not the LLM, controls the workflow, budgets and retries.
  • Runs entirely on self-hosted LLM inference with Ollama, so no company data leaves the building. Agents reach Kubernetes, Jira and internal docs through read-only MCP tool servers that hold their own credentials. Long tool output is trimmed before the model reads it, and workers save a checkpoint after every turn so a retry resumes where the last attempt stopped.
  • Enforced safety with infrastructure rather than prompts: tools classed by risk with read-only access for the first rollout, Kubernetes RBAC and network policy, company single sign-on (Keycloak), hashed API keys and an audit record written before every authenticated call. Final reports follow a fixed schema with an approved list of actions.
  • Built record and replay into every tool server, so agents can be tested offline against past incidents after the cluster has moved on. Also built the shared logging layer for agent events, reports and audit records in OpenSearch, and CI checks for leaked secrets, database migrations and integration tests (pytest).
  • Loaded more than 100,000 past Freshservice support tickets into self-hosted OpenSearch, pacing the import to stay within the API's rate limits. The tickets support search and retrieval for the agent platform.
  • Built a Kubernetes pipeline that generates tens of thousands of marketing images from business data in a single day. The manual process it replaced took a month.
  • Rebuilt the mobile build system as a set of small Python services behind one API that provisions, builds, signs and ships each app. It supports all 300+ iOS and Android apps. A full rebuild of the fleet is about 600 build jobs and takes 24 to 48 hours.
  • Built a self-service deployment platform and am leading the company-wide CI/CD migration from Azure DevOps to GitHub Actions. The platform checks a team's code, runs tests and security scans, builds a container image and deploys it to Kubernetes.
