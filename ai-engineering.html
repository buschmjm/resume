Design and build internal AI systems while running the platform and release infrastructure behind more than 300 white-label iOS and Android apps in production. On-call owner and final escalation point for production incidents.

  • Designing a general-purpose AI agent platform for internal use. A task names an agent and supplies its input, and a dispatcher written in ordinary code starts a short-lived Kubernetes worker to run it. The dispatcher, not the LLM, decides what runs and when. The design also includes MCP tool servers, a supervisor and a CLI.
  • Building it on self-hosted LLM inference with Ollama. PostgreSQL with pgvector (vector database) holds tool definitions and agent context, and OpenSearch holds agent output and logs. Model serving is running and in use today. The dispatcher and workers are still in development.
  • Designed checks so an agent's output is reviewed before any later step relies on it. The access design uses company single sign-on (Keycloak), role-based permissions, hashed API keys and an audit record for every authenticated action.
  • Built the shared logging layer that records agent events, work reports and audit records in PostgreSQL and OpenSearch. It buffers and retries writes, counts any events it has to drop and expires old data on a schedule. Added CI checks for leaked secrets, database migrations and integration tests (pytest).
  • Loaded more than 100,000 past Freshservice support tickets into self-hosted OpenSearch, pacing the import to stay within the API's rate limits. The tickets support search and retrieval for the agent platform.
  • Built a Kubernetes pipeline that generates tens of thousands of marketing images from business data in a single day. The manual process it replaced took a month.
  • Rebuilt the mobile build system as a set of small Python services behind one API that provisions, builds, signs and ships each app. It supports all 300+ iOS and Android apps. A full rebuild of the fleet is about 600 build jobs and takes 24 to 48 hours.
  • Built a self-service deployment platform and am leading the company-wide CI/CD migration from Azure DevOps to GitHub Actions. The platform checks a team's code, runs tests and security scans, builds a container image and deploys it to Kubernetes.
